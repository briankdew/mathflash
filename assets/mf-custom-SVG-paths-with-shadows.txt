INKSCAPE INSTRUCTIONS TO GENERATE SHADOW IMAGES IN SVG FILES
1. Select the shape/object that needs a shadow.
2. Apply a shadow filter ('Inner cutout' or 'Outer cutout') to the shape as needed (Filters > Shadows and Glows > Drop Shadow... > Options > Shadow type menu) to generate the shadow (only).

IMPORTANT! Before proceeding to Step 3, make sure the 'Resolution for Create Bitmap Copy' (Edit > Preferences > Imported Images menu) is set to 400 dpi.

3. Select the shadow shape/object and use 'Make a Bitmap Copy' (Edit menu) to create the image of (just) the shadow (everything else remains transparent).
4. Select the shadow shape/object (not the shadow image) and use 'Remove Filters' (Filters menu) to restore the object to its original styling (fill and stroke colors, etc.).
5. Save the SVG file as an 'Optimized SVG' (File > Save As... Optimized SVG (*.svg) menu) to remove unnecessary information from the SVG file for use in the app.
